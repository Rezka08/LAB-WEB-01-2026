# kopi-senja

Website pemesanan mandiri Kedai Kopi Senja — Praktikum 7 React Hooks (State & Props).

## Menjalankan proyek
1. Pastikan Node.js sudah terpasang.
2. Buka terminal di folder `kopi-senja`.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.
5. Buka alamat lokal yang ditampilkan Vite di browser.

## Teknologi
- React + Vite (JavaScript JSX)
- Tailwind CSS
- `useState` sebagai state hook
- Props untuk komunikasi komponen

## Fitur
- 9 menu sesuai data soal.
- Filter kategori: Semua, Kopi, Non-Kopi, Makanan.
- Detail menu dapat dibuka per kartu.
- Menu yang tidak tersedia tidak bisa ditambahkan.
- Jumlah item dan total harga dihitung dari satu state keranjang.
- Validasi nama, nomor meja, dan pesanan.
- Pesanan sukses menampilkan ucapan terima kasih dan mengosongkan form/keranjang.

Warna visual terinspirasi dari palet hijau dan krem kedai kopi modern; bukan situs resmi Fore Coffee.
